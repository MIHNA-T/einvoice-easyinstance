ConvergeX Configuration

Enter your ConvergeX (convergex.biz) Client ID, Client Secret, and invoice type UUIDs directly from Settings > Invoicing > ConvergeX (Oman E-Invoicing), then verify them with Test Connection.

Submit to ConvergeX

One click on a posted invoice sends the invoice data straight to ConvergeX's Customer Invoice API - no manual XML file or upload needed.

Submission Status Ribbon

A "Submitted" ribbon shows right on the invoice the moment ConvergeX accepts it - no need to open a separate record just to check status.

Tracking Number & QR Code

Every submission gets its own ConvergeX Documents record: the ConvergeX Invoice ID, tracking number, processed reference, and OTA QR code, all in one place.

Our Core Features

Direct JSON Submission

Sends invoice and credit note data straight to ConvergeX's Customer Invoice API as structured JSON - ConvergeX generates the compliant PINT OM e-invoice, QR code, and OTA submission itself.

Automatic Customer Master Sync

Every buyer is synced to ConvergeX's Customer Master before submission, exactly as required for its PEPPOL network checks - handled automatically, with no separate setup step.

Credit Note Support

Submits credit notes with the required preceding invoice references straight from Odoo's own Credit Note flow - no extra data entry needed.

B2B / B2C Auto-Detection

The correct BTOM-001 transaction type - Full Tax B2B or Simplified B2C - is set automatically from whether the buyer is a company, with no manual toggle to get wrong.

QR Code & Tracking

Captures the OTA QR code, ConvergeX tracking number, and processed reference straight from the API response onto a dedicated ConvergeX Documents record.

One-Click Test Connection

Verify your ConvergeX Client ID and Client Secret directly from Settings, with a dedicated Test Connection button - before submitting a single invoice.

Oman VAT Format Validation

Validates the Oman VAT format ("OM" + 10 digits) the moment a customer is saved in Odoo, catching bad data before ConvergeX ever rejects it at submission.

Status Polling Cron

A scheduled action polls ConvergeX for the latest status on every submitted document until it's acknowledged by the Oman Tax Authority - no manual refresh needed.

Frequent Questions

Does this module build the e-invoice XML itself?

No. ConvergeX's API takes structured JSON directly - this module builds that JSON from your posted invoice/credit note and sends it to ConvergeX, which generates the compliant PINT OM e-invoice XML, QR code, and PEPPOL/OTA submission on its own platform.

Do I need my own ConvergeX account to use this module?

Yes. This module is a connector, not a ConvergeX subscription - you'll need your own ConvergeX (convergex.biz) account with a Client ID and Client Secret. Enter them in Settings > Invoicing > ConvergeX and use the Test Connection button to verify they work before submitting any invoices.
